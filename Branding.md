# SCOPE name and project identity

"SCOPE" identifies the official SCOPE computational chemistry software
developed and maintained by the QTC-IQAC developers.

The SCOPE source code is distributed under the PolyForm Noncommercial
License 1.0.0. The software license permits modification and redistribution
for the purposes specified by that license.

## Modified versions

To avoid confusion between the official SCOPE distribution and independently
modified versions, modified distributions of the SCOPE core should:

- clearly state that they are derived from SCOPE;
- clearly state that they are not official releases of SCOPE and are not
  maintained or endorsed by the SCOPE developers; and
- use a name that is clearly distinguishable from the official SCOPE
  distribution.

Contributions intended for inclusion in the official SCOPE core are encouraged
through the project's GitHub repository.

## Add-ons

Independent packages extending SCOPE through its add-on architecture are
encouraged. Such packages may describe themselves as "add-ons for SCOPE",
"compatible with SCOPE", or similar, provided that this does not imply that
they form part of, or are endorsed by, the official SCOPE distribution.
